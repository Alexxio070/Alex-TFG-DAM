# Tests de la app

Documentación de los tests de [`App-movil/test/`](../../App-movil/test/): qué prueba cada archivo y para qué sirve. Hay 252 tests, todos automáticos; ninguno depende de un móvil, de la red ni del agente real.

```bash
cd App-movil && flutter test                    # todos
cd App-movil && flutter test test/<archivo>.dart  # uno solo
```

Casi todos usan repositorios falsos o en memoria: prueban la app, no su conexión real con el agente. Las pruebas de esa conexión son `http_metrics_repository_test` y `http_auth_repository_test` (cliente HTTP simulado), `iroh_connection_test`, `iroh_metrics_repository_test` e `iroh_auth_repository_test` (conexión iroh falsa). Las pruebas con el agente real (por USB con `adb reverse`) se hicieron a mano en la fase 1 y constan en el [plan de fases](../documentos-generales-del-proyecto/04-plan-de-fases.md).

## Apoyo (no son tests)

| Archivo | Para qué sirve |
|---|---|
| [`helpers/app_harness.dart`](../../App-movil/test/helpers/app_harness.dart) | `app()` monta la `SysmoteApp` completa con todos los repositorios falsos o en memoria y, por defecto, con la sesión ya abierta (un `FakeAuthRepository.loggedIn()` y su token guardado); `startApp()` monta la app y espera a que se carguen los ajustes y arranque la sesión (la sesión no arranca hasta tener los ajustes); `pumpFor()` avanza el reloj falso a saltos de 100 ms para esperar animaciones y futuros. Lo usan todos los `*_widget_test.dart`. `openSection()` fija el tamaño de pantalla, monta la app y abre una sección desde el menú lateral (lo usan los tests de Métricas, Notas, Terminal y Ajustes) |
| [`fakes/fake_metrics_repository.dart`](../../App-movil/test/fakes/fake_metrics_repository.dart) | Métricas aleatorias (CPU, RAM, temperatura) y 3 particiones de ejemplo (`/`, `/home`, `/mnt/datos`) |
| [`fakes/fake_auth_repository.dart`](../../App-movil/test/fakes/fake_auth_repository.dart) | Simula el agente en el login, el registro y la sesión según el contrato de la fase 3: credenciales y código de registro configurables, solicitud pendiente que se aprueba o rechaza a mano, límite de intentos con bloqueo y un token que `session()` da por caducado (`tokenCaducado`); `FakeAuthRepository.loggedIn()` lo deja con la sesión ya abierta |
| [`fakes/in_memory_settings_repository.dart`](../../App-movil/test/fakes/in_memory_settings_repository.dart) | Guarda los ajustes en una variable en memoria en vez de en `shared_preferences` |
| [`fakes/in_memory_token_storage.dart`](../../App-movil/test/fakes/in_memory_token_storage.dart) | Guarda el token de sesión en una variable en memoria en vez de en el almacenamiento cifrado de Android |
