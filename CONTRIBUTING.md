# Contribuir a Sysmote

Es un proyecto de fin de grado y todavía no tiene una guía de contribución formal. Las ideas y los fallos que encuentres se pueden comentar abriendo una incidencia (*issue*). `main` es la rama estable y recibe los cambios mediante pull request, desde una rama propia cortada de `main` (por ejemplo `feature/<nombre>` o `fix/<nombre>`). Los mensajes de commit siguen el formato convencional (`feat:`, `fix:`, `docs:`...).

# Contributing to Sysmote

This is a final-year project and does not have a formal contribution guide yet. You can share ideas and report bugs by opening an issue. `main` is the stable branch and receives changes through pull requests, from your own branch cut from `main` (for example `feature/<name>` or `fix/<name>`). Commit messages follow the conventional format (`feat:`, `fix:`, `docs:`...).
