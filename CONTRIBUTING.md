# Contributing to Sysmote

This is a final-year project and does not have a formal contribution guide yet. You can share ideas and report bugs by opening an issue. The branches are `main` (stable) and `feature/<name>` for each task, and commit messages follow the conventional format (`feat:`, `fix:`, `docs:`...).
